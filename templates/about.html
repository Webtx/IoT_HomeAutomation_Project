CTRLHOUSE

IoT Home Automation & Security System

CTRLHOUSE is a comprehensive IoT-based home automation and security system that combines environmental monitoring, device control, and security features in an elegant, user-friendly web interface. Built with Flask and powered by cloud technologies, it provides real-time monitoring and control of your smart home from anywhere in the world.

Key Features

Environmental Monitoring

Track temperature, humidity, and pressure readings from Raspberry Pi sensors with historical data visualization.

Device Control

Remotely control home devices (LED, Fan, Relay) through Adafruit IO integration.

Security System

Enable/disable security monitoring and view motion detection history.

Cloud Integration

Data stored in Neon PostgreSQL cloud database with Render deployment.
